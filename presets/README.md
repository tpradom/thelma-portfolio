# Alpine Pack

Four matching looks: faded matte blacks, rich greens and oranges, deep blues.

| Look | Mood |
| --- | --- |
| Alpine 01 Golden Ridge | Olive shadows, glowing orange rock, deep alpine blues |
| Alpine 02 Glacier | Cool, crisp, icy blue shadows |
| Alpine 03 Moss | Earthy, heavy fade, mossy greens |
| Alpine 04 Ember | Soft sunset, pink-orange highlights |

## Photos (`Lightroom-XMP/`)

- **Lightroom Classic:** Presets panel → `+` → Import Presets.
- **Lightroom desktop / mobile:** Edit → Presets → `⋯` → Import Presets.

Grain, texture and clarity are only in the XMP files.

## Video (`Video-LUTs/`)

33-point `.cube` LUTs for Rec.709 footage. Import into CapCut, Premiere, DaVinci Resolve, Final Cut, etc., and lower the intensity if it feels strong. LUTs can't carry grain.
